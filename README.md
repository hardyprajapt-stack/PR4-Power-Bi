# PR4-Power-Bi
Employee &amp; HR Analytics Dashboard built in Power BI to analyze total, active and terminated employees, salary, performance, training, engagement and hiring trends. Used Power Query, Data Modeling, DAX Measures, Calculated Columns, Time Intelligence, Slicers and interactive visuals to create a professional HR analytics dashboard.

📊 Employee & HR Analytics Dashboard – Power BI

📌 Project Overview

This project is an Employee & HR Analytics Dashboard created using Microsoft Power BI.
The dashboard helps analyze employee data, workforce status, salary, training, performance, engagement, recruitment and hiring trends.

🎯 Project Objectives

- Analyze total and active employees
- Track terminated employees and attrition
- Analyze average and total salary
- Analyze employee performance
- Analyze training and employee engagement
- Understand hiring trends
- Compare HR performance using interactive dashboards

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Calculated Columns
- Time Intelligence
- Slicers & Filters
- Power BI Visualizations

🗂️ Data Model

The project contains the following main tables:

- EmployeeMaster
- Training
- EngagementSurvey
- Performance
- Recruitment
- DimDate

EmployeeMaster is used as the main employee table, while DimDate supports date-based analysis.

📐 DAX Measures

Important measures created in the project include:

- Total Headcount
- Active Headcount
- Terminated Count
- Average Salary
- Total Salary Cost
- Attrition Rate
- Training Cost
- Employee Performance Metrics

These measures respond dynamically to filters and slicers.

🔢 Calculated Columns

Some important calculated columns include:

- Performance_Label
- Salary_Formatted
- Days_Since_Hire
- Hire_Year_Month

These columns help make the data easier to analyze and understand.

📊 Dashboard Features

The dashboard includes:

- KPI Cards
- Employee Headcount Analysis
- Active vs Terminated Employees
- Salary Analysis
- Performance Analysis
- Training Analysis
- Hiring Trends
- Attrition Analysis
- Interactive Slicers
- Time-based Analysis
